# 🌐 Personal Portfolio Website

A modern, responsive, and user-friendly personal portfolio website developed using HTML, CSS, and JavaScript.  
This project showcases my skills, projects, resume, and contact information in a clean and professional way.

---

# 📌 Features

✅ Fully Responsive Design  
✅ Modern UI/UX  
✅ Smooth Scrolling Navigation  
✅ About Me Section  
✅ Skills Showcase  
✅ Projects Section  
✅ Resume Download Option  
✅ Contact Form  
✅ Social Media Links  
✅ Mobile Friendly Layout  
✅ Clean and Organized Code  

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Devicon Icons
- Google Fonts


## 2️⃣ Navigate to Project Folder


## 3️⃣ Run the Project

Simply open:

```bash

```

in your browser.
